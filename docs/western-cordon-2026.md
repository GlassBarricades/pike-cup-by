# Чеклист: «Западный Кордон 2026»

После применения миграций `016_formats.sql`, `017_tournament_draw_slips.sql` и `018_athlete_junior.sql` в Supabase.

## Подготовка

1. Создать лигу **Брестская область** (`/leagues` → тип «Областная», регион Brest).
2. Создать турнир на **21.11.2026**, место — гребной канал Брест.
3. Формат: пресет **«БООР: личный + командный»** (или вкладка «Формат»). При отдельном зачёте юниоров — включить **«Отдельный зачёт юниоров»**.
4. Включить типовое расписание (шаблон БООР: 2×3 мини-тура).
5. Вкладка **«Бумажки»**: пакет Кордона (52 шт.) создаётся при создании турнира; при необходимости — «Создать пакет» / «Перезалить».
6. В справочнике рыбаков проставить **Юниор** тем, кто идёт в юниорский зачёт (снимок попадёт в заявку).
7. Завести заявки: команды со составом **2** спортсмена; при необходимости капитан/представитель. Одиночки — блоком «Участник без команды» (только личный зачёт; там же чекбокс «Юниор»).
8. Жеребьёвка (`/staff/draw`): выдать бумажку — **вручную** кто в A, напарнику остаются только бумажки B (и наоборот). Одиночки — любая свободная. Либо «Разыграть» / ручной ввод зона/сектор.
9. Назначить судей зон A и B.

## Тестовый прогон (до боевого дня)

1. Создать копию турнира (или черновик) и проставить тестовые веса в пульте.
2. Проверить:
   - пульт: список спортсменов своей зоны на текущий мини-тур;
   - `/live/t/:id/table` — командный и личный зачёт;
   - лента уловов;
   - штаб → взвешивание по спортсмену.
3. Удалить тестовый турнир.

## Боевой день

1. Статус турнира → «Идёт» по мере старта.
2. Судьи работают в `/staff/console`.
3. Зрители — `/live` и таблицы на карточке турнира.

## Важно

- Уловы пишутся на **спортсмена** (`roster_member_id`).
- Бумажки принадлежат **турниру** — пакет Кордона не пересекается с PikeCup.
- Участники без команды (`team_id` null) считаются только в личном зачёте.
- В паре зоны I тура разные: первая бумажка задаёт сторону, вторая — только противоположная.
- При «Отдельный зачёт юниоров»: личные таблицы **общий** (без юниоров) и **юниоры**; командный один.
- Формат нельзя менять после первого улова.
- Замена состава между турами — пока ручная правка заявки в штабе.
